  ★ Insight ─────────────────────────────────────
  Kenapa yard-planning tidak pakai React hooks dari vehicle-path2?

  yard-planning menggunakan arsitektur yang berbeda fundamental: mereka punya Orchestrator class (bukan React state) sebagai sumber kebenaran tunggal, yang di-share ke seluruh app lewat useOrchestrator(). Karena useVehicleSimulation dirancang untuk owns state-nya sendiri lewat React hooks, ia tidak kompatibel 
  dengan pola imperative class ini. Makanya PathEngine dibuat sebagai wrapper tipis di atas core functions saja.

  Ini juga menjelaskan kenapa moveVehicle yang non-existent itu di-import — kemungkinan ada rencana untuk membungkus updateAxlePosition dengan nama yang lebih ringkas, tapi belum di-implement di sisi vehicle-path2.
