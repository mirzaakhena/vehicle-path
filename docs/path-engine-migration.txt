PATH ENGINE MIGRATION — SESSION SUMMARY
========================================
Date: 2026-03-05


BACKGROUND
----------
Project yard-planning menggunakan vehicle-path2 sebagai dependency untuk
simulasi pergerakan truk. Dalam sesi ini dilakukan analisis cross-project
untuk memahami pola penggunaan dan menemukan kode yang seharusnya hidup
di vehicle-path2, bukan di yard-planning.


ANALISIS: APA YANG DIPAKAI YARD-PLANNING DARI VEHICLE-PATH2
-------------------------------------------------------------
yard-planning hanya menggunakan entry point `vehicle-path2/core` (bukan
/react atau /utils). Fungsi yang dipakai:

  Dari pathFinding.ts:
    - buildGraph

  Dari vehicleMovement.ts:
    - prepareCommandPath
    - calculateInitialFrontPosition
    - getLineLength
    - moveVehicle  <-- BUG: fungsi ini TIDAK ADA di vehicle-path2

  Dari math.ts:
    - createBezierCurve
    - getPointOnBezier
    - resolveFromLineOffset
    - resolveToLineOffset

Seluruh React layer (useVehicleSimulation, useScene, useVehicles, dll.)
dan utils layer (DSL parser, event emitter, animation loop) tidak dipakai
sama sekali.


ALASAN: KENAPA YARD-PLANNING TIDAK PAKAI REACT HOOKS
------------------------------------------------------
yard-planning menggunakan arsitektur Orchestrator (singleton class) sebagai
sumber kebenaran tunggal — bukan React state. useVehicleSimulation dirancang
untuk owns state-nya sendiri via React hooks, sehingga tidak kompatibel
dengan pola imperative class ini.

Akibatnya, yard-planning membuat PathEngine class sendiri di
src/core2/path-engine.ts sebagai stateful wrapper atas vehicle-path2 core
functions.


TEMUAN: GAP DI VEHICLE-PATH2
------------------------------
1. Tidak ada class-based / imperative API
   vehicle-path2 hanya menyediakan: functional core ATAU React hooks.
   Tidak ada pilihan untuk non-React consumers.

2. Fungsi moveVehicle tidak ada
   yard-planning mencoba import `moveVehicle` dari vehicle-path2/core tapi
   fungsi ini belum exist. Ini menyebabkan runtime error. Fungsi ini
   seharusnya membungkus dua panggilan updateAxlePosition (rear + front)
   menjadi satu call sederhana dengan arrival detection.
